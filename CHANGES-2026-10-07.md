# Cobra Launcher changes (2026-10-07)

## Item Physics (was not implemented at all)
The module existed but nothing used it. Now (client/.../ItemPhysicsFx.java + ItemEntityRendererMixin
+ ItemEntityRenderStateMixin):
- flat items fall over and lie flat; blocks rest on a face at their own random turn
- items tumble while flying (faster when thrown harder) and roll onto the nearest side when they land
- flat items float and rock in water; stacks lie in a small pile; no bobbing or spinning
- setting: "Tumble in the air" (0 = no tumbling)

## Waypoints
- Right Shift menu → Waypoints: click a name to rename it, click the colour square for the colour wheel
- pressing B opens a name box for the new waypoint (setting "Name it when you add one")
- the list scrolls and shows distance; new markers in game (diamond, line down to the spot,
  name + distance label), "Label size" slider

## Screen recorder quality
- NVENC: constant quality now really works (-b:v 0; before, ffmpeg's tiny default bitrate capped it)
- better presets / adaptive quantisation for x264, NVENC, VA-API, QSV, AMF
- correct BT.709 colour conversion and tags (colours were shifted / washed out before)
- frames copied on two threads can no longer arrive out of order (stutter)
- smooth resize when the window changes size mid-recording
- new setting "Encoder": Auto / Graphics card / CPU (sharpest)
- gpu-screen-recorder: constant frame rate, colour range, quality mode, no cursor (only the options
  your installed version supports are passed)

## Spotify album cover
- Spotify sends JPEG covers; Minecraft only loads PNG, so the cover never showed. Covers are now
  converted (rounded corners), broken open.spotify.com/image links are fixed, and when there is no
  cover link (Windows, local files) it's looked up by artist + title
- the progress bar and card take the cover's colour

## Accessories
All cosmetics rebuilt from smooth shapes (tapered tubes, domes, rings, gems) with colour gradients
instead of flat single-colour boxes (common/.../cosmetics/Shapes.java). Static ones are built once
and cached, so the extra detail stays cheap. The launcher preview shows the gradients too.
